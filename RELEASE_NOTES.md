What's new in EtherDrop Mobile v1.0.0

- Share files and folders with Windows and Android devices on the same Wi-Fi network or hotspot.
- Approve incoming files, choose a destination, and follow transfer progress and diagnostics.
- Continue transfers in the background, with reconnection and optional SHA-256 verification.
- Check for GitHub releases, review update notes and download size, and approve APK downloads inside the app.
- Install updates through Android's installer and view release notes after updating.
- Fix the incorrect startup error when choosing Send files or Receive files.
